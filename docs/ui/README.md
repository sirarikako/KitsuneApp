# KitsuneApp UI 设计稿

更新日期：2026-11-23（Asia/Shanghai）。此处保存与 Android 实现同步维护的网页设计稿。

正式设计仅保留原杏橙手账的统一组件造型，默认杏橙配色。茶绿、雾蓝、薰衣草、豆沙粉及自选主色、系统壁纸取色继续保留，所有配色使用同一布局与形状规范；无独立视觉方案切换。业务规则按 [功能设计导航](../README.md) 查阅，数据契约按 [数据契约索引](../DATA_FORMAT.md) 查阅；本目录提供可查看、可编辑的视觉依据。

## 查看与维护

直接用现代 Edge 或 Chrome 打开 [index.html](index.html)，可离线查看，无需启动服务或安装 Android 工具链。预览仅显示唯一设计，手机界面内可切换首页、用餐、记账、设置；在设置中修改配色和明暗。

## 视觉与页面索引

当前源稿的手机画布最大宽度为 390 CSS px。卡片圆角统一为 17 px，不随调色板变化。用餐的按日记录、筛选结果和账本流水共用同一记录行，基准高度为 70 CSS px，随内容增高。筛选控件、录入表单和统计面板也共用样式，见 [共用界面规范](../features/01-common.md#31-用餐与账本的共用界面)。Android 实现需转为合适的 dp／sp，并适配字体缩放和屏幕宽度。

当前通用容器采用「主题卡片底色 + 1px 描边」：首页收支与三餐进度、用餐和账本记录、统计、设置分组及外观预览一致；普通输入、筛选、次要操作与计算器数字键也使用细描边。仅主要动作、选中态、危险确认和有意义的标识／图表保留实色强调。所有配色共用圆角、描边与组件形状，不再存在独立备选造型。

共用控件、间距、文字层级、图标和弹窗采用 [共用界面规范](../features/01-common.md#31-用餐与账本的共用界面)的尺寸规范。外观预览复用实际记录、标签与主要按钮的样式，独立生成完整主题角色；网页颜色生成按 WCAG 相对亮度对文字、选中、主操作及危险操作进行对比度调整，目标至少 4.5:1。

预设与自选主色的背景、卡片、文字、边框、强调和收支颜色采用 HTML 源稿的展示角色。每套预设以自己的种子色生成页面、卡片、柔和底色和描边色阶。Android 以 Tonal Spot 提供其余 Material 角色。系统壁纸配色使用设备提供的不同中性色阶区分页面背景和卡片，离线预览以固定示例展示同样的层次。具体规则见 [外观模块](../features/07-appearance.md) 与 [共用规范](../features/01-common.md)。

Android 的导航、用餐餐次、账目和设置图标取自预览使用的 Lucide v1.8.0。首页狐狸采用共同的原创资产，预览打包脚本将缩略图内嵌并记录哈希。

页面通过交互预览查看；当前不保留静态 UI 截图。

预览在载入初始外观时以中性底色显示空画布，首帧页面使用载入的配色。Android 启动窗口和读取中的界面使用相同的浅色／深色中性底色，再直接显示已保存的外观。

## 全局动效设计

页面过渡、弹层、记录详情、局部内容更新和外观变更统一遵循 [动效规范](../features/01-common.md#32-全局动效与页面过渡)。四个底部入口采用 Fade Through；层级导航、记录容器变形及临时弹层按场景区分。同一套规则适用于全部配色及明暗模式，不改变现有页面布局及业务入口。

网页源稿和离线预览包含四页淡入淡出、子页双向滑动、可见记录来源的容器裁剪展开／收回（不满足条件时水平过渡）、计算器底部弹层、日期范围／钱包范围／删除确认居中弹窗、日期／页内标签／筛选结果淡入淡出以及外观预览区高度过渡。应用主题时同明暗模式下插值颜色角色，跨明暗直接同步替换前景／背景以避免低对比度中间帧。网页使用 Web Animations API，遵循 prefers-reduced-motion；Android 正式实现遵循对应功能模块及公共动效规范。

## 首页双卡片布局（2026-11-23）

首页“今日用餐”和“本月收支”统一采用卡片内部标题与右侧详情入口。卡片间距 16px（Android 16dp），共享现有 17px 圆角、1px 主题细描边、16px 内边距及主按钮规格。用餐卡片依次显示标题、进度、三餐状态和全宽操作。收支卡片依次显示标题、各币种的净支出与收入和全宽操作。币种单独一行，金额超过列宽时改用整行。详情箭头均用 chevron-right。业务规则见 [首页模块](../features/02-home.md)。

本轮对应源稿为 `src/pages/02-home.js.inc`、`src/styles/02-components.css.inc`，Android 对应 `MainActivity.kt` 中的 `Home`。离线预览由相同版本的源稿生成。

## 记账交互

流水、钱包和统计共用吸顶标签。滚动正文时标题与适用的筛选逐步收起，反向滚动时展开。按月时日期与钱包同行，自定义日期时起止日期独占第一行。月份弹窗保留逐月浏览和直接选择月份。流水中的摘要和高级筛选随正文滚动。

流水右下角的“记一笔”随滚动收为圆形加号，回到顶部或重新进入时展开。钱包和统计用各自的正文区域。首页“本月收支”卡片底部使用全宽“记一笔”按钮，标题行保留“查看账本”。收支合计有 CNY 时将其排在第一行，其余币种沿用原顺序。

记账表单的金额位于收支类型下方，点击整块金额打开底部计算器。金额和表达式使用只读显示，计算器按键修改表达式，取消保留已填金额，确认后回填。预览提供新增收支的交互样例。Android 的跨币种转账、编辑和退款沿用正式业务流程。

## 本轮独立核算设计更新

钱包卡片缩减内边距和纵向间距，名称旁显示“默认钱包”“独立核算”及“已归档”标识。右上角的标签和铅笔图标分别进入专属分类管理和钱包编辑。在编辑页保存默认钱包后，首页和账本的“记一笔”均可预选该钱包，独立核算钱包也适用。账本的“钱包范围”支持常规钱包、全部钱包和手动选择。首页收支仍按常规钱包计算。

分类管理新增“设置 → 通用收支分类／钱包专属分类”入口及钱包卡片快捷入口。两类均区分收入、支出；钱包可各自设置 DEFAULT／CUSTOM，CUSTOM 空列表不自动回退通用词表，始终保留通用“未分类”。演示新增、改名和停用分类，记账表单随钱包与类型切换可选列表，同名分类使用演示 ID 区分。Android 的分类生命周期、排序、历史编辑、CSV 作用域解析、JSON 备份和退款关系按 [分类模块](../features/06-categories.md) 与 [数据契约](../DATA_FORMAT.md) 实现。
