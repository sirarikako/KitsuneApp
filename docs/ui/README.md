# KitsuneApp UI 设计稿

更新日期：2026-11-22（Asia/Shanghai）。此处保存与 Android 实现同步维护的网页设计稿。

正式设计仅保留原杏橙手账的统一组件造型，默认杏橙配色。茶绿、雾蓝、薰衣草、豆沙粉及自选主色、系统壁纸取色继续保留，所有配色使用同一布局与形状规范；无独立视觉方案切换。业务规则按 [功能设计导航](../README.md) 查阅，数据契约按 [数据契约索引](../DATA_FORMAT.md) 查阅；本目录提供可查看、可编辑的视觉依据。

## 查看与维护

直接用现代 Edge 或 Chrome 打开 [index.html](index.html)，可离线查看，无需启动服务或安装 Android 工具链。预览仅显示唯一设计，手机界面内可切换首页、用餐、记账、设置；在设置中修改配色和明暗。

## 视觉与页面索引

当前源稿的手机画布最大宽度为 390 CSS px。卡片圆角统一为 17 px，不随调色板变化。用餐的按日记录、筛选结果和账本流水共用同一记录行，基准高度为 70 CSS px，随内容增高。筛选控件、录入表单和统计面板也共用样式，见 [共用界面规范](../features/01-common.md#31-用餐与账本的共用界面)。Android 实现需转为合适的 dp／sp，并适配字体缩放和屏幕宽度。

当前通用容器采用「主题卡片底色 + 1px 描边」：首页收支与三餐进度、用餐和账本记录、统计、设置分组及外观预览一致；普通输入、筛选、次要操作与计算器数字键也使用细描边。仅主要动作、选中态、危险确认和有意义的标识／图表保留实色强调。所有配色共用圆角、描边与组件形状，不再存在独立备选造型。

共用控件、间距、文字层级、图标和弹窗采用 [共用界面规范](../features/01-common.md#31-用餐与账本的共用界面)的尺寸规范。外观预览复用实际记录、标签与主要按钮的样式，独立生成完整主题角色；网页颜色生成按 WCAG 相对亮度对文字、选中、主操作及危险操作进行对比度调整，目标至少 4.5:1。

颜色和组件的实现以 [外观模块](../features/07-appearance.md) 与 [共用规范](../features/01-common.md) 的主题规则为准。网页使用带文字对比度保护的近似颜色混合，尚未采用 Android Material Color Utilities 的完整 Tonal Spot 色阶。

页面通过交互预览查看；当前不保留静态 UI 截图。

## 全局动效设计

页面过渡、弹层、记录详情、局部内容更新和外观变更统一遵循 [动效规范](../features/01-common.md#32-全局动效与页面过渡)。四个底部入口采用 Fade Through；层级导航、记录容器变形及临时弹层按场景区分。同一套规则适用于全部配色及明暗模式，不改变现有页面布局及业务入口。

网页源稿和离线预览现已加入四页淡入淡出、子页双向滑动、可见记录来源的容器裁剪展开／收回（不满足条件时水平过渡）、计算器和钱包底部弹层、删除确认、日期／页内标签／筛选结果淡入淡出以及外观预览区高度过渡。应用主题时同明暗模式下插值颜色角色，跨明暗直接同步替换前景／背景以避免低对比度中间帧。网页使用 Web Animations API，遵循 prefers-reduced-motion；Android 正式实现遵循对应功能模块及公共动效规范。

演示没有登录功能，也不会连接 GitHub 或读写个人数据。演示记录、钱包余额及所有金额均为虚构样例；旅行钱包初始标记为独立核算，首页及账本默认不纳入，但钱包页仍显示余额。全部钱包初始使用通用收入／支出分类；通过设置页可为任意钱包分别开启专属模式和添加类别。网页预览的新增、编辑、归档类别及示例记账只在当前运行期间模拟；刷新会重置这些演示业务数据，部分其他页面偏好可能由浏览器本地存储保留。

“跟随系统壁纸”在网页中使用固定示意色板，Android 使用 Android 12 及以上系统提供的 Material 动态颜色。独立的“外观与调色板”子页有未应用的外观修改时才显示预览、“取消”和“应用外观”。应用成功、取消或改回已应用值后收起预览区。“预览明暗”只切换示例区域。切换来源保留上次预设／自选色。具体规则见 [外观模块](../features/07-appearance.md#6-外观调色板与系统主题)。

日期、分类、钱包、ID 与金额的演示结构不是正式 JSON／CSV 数据格式。正式开发需按[数据契约](../DATA_FORMAT.md)建模，按 [记账](../features/05-ledger.md)、[数据管理](../features/08-data-management.md)、[备份](../features/09-backup.md)及[分类管理](../features/06-categories.md)完成转账原子性、退款保护、金额范围和精度、备份、分类生命周期等全部规则，不能把网页的演示限额、固定选项或简单数组当作完整实现。

## 本轮独立核算设计更新

钱包卡片显示“独立核算”标识，从“编辑钱包”进入子页修改并保存；账本筛选新增默认常规钱包、手选钱包和全部（含独立核算）的明确区别。首页收支始终按常规钱包计算，新建记账不自动选独立核算钱包。

分类管理新增“设置 → 通用收支分类／钱包专属分类”入口及钱包卡片快捷入口。两类均区分收入、支出；钱包可各自设置 DEFAULT／CUSTOM，CUSTOM 空列表不自动回退通用词表，始终保留通用“未分类”。演示新增、改名和停用分类，记账表单随钱包与类型切换可选列表，同名分类使用演示 ID 区分。Android 的分类生命周期、排序、历史编辑、CSV 作用域解析、JSON 备份和退款关系按 [分类模块](../features/06-categories.md) 与 [数据契约](../DATA_FORMAT.md) 实现。

本轮删除备选视觉原型及切换入口，仅保留单一手机预览。静态检查 JavaScript 语法通过；逐一比较 222 个种子色在常规／系统示意取色和明暗下的完整颜色角色，保留方案的颜色结果与原实现完全一致。重新打包离线 HTML 并更新校验清单；尚未执行当前版本浏览器视觉回归。

本轮动效更新检查了源稿 JavaScript 语法、原预览和源稿哈希，按原打包规则替换独立预览中转义的源片段并重算 SHA-256；保留模板与图标字节不变。尚未进行浏览器实际渲染、快速连续点击与配色／明暗／窄屏回归，Android 动效亦未实现。不能将静态检查视为实测通过。

本轮资料清理移除 18 张旧截图、191 条被覆盖的 CSS 声明（涉及 77 条规则）及 8 条未使用的样式规则。业务 JavaScript 与页面标记保持不变；重新生成独立预览与校验清单，尚未执行浏览器视觉回归。
