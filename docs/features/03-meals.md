# 用餐功能设计

> 本文包含最新确认的用餐规则和全部详细需求。

## 最新确认的用餐规则

以下修改优先于早期方案：

1. **“是否计划在家吃”必填，只能选择“是／否”。** 新建表单默认选择“是”；编辑显示原记录的选择。
2. **删除原来的“是否下厨”布尔字段，改为“用餐方式”单选分类。** 初始选项为“下厨、外卖”。新建表单默认选中可用的内置“下厨”，也可在设置中维护选项。
3. 计划在家吃为“是”时，用餐方式必须选择一项；为“否”时仍显示，可以不填，但最多选择一项。
4. 每种用餐方式都可以设置“显示制作分类”。默认“下厨”开启、“外卖”关闭；新增方式默认关闭，可自行开启。
5. “炒菜、预制菜”等是独立的、多选的**制作分类**，不是用餐方式。“用餐方式”和“制作分类”的选项后都提供加号，弹窗输入名称并确认后加入现有列表。
6. “是”改为“否”时保留已填写的用餐方式和制作分类。不能自动把“外卖”等同于“不在家吃”，也不能根据计划自动推断实际方式。


## 4. 用餐功能详细规则

### 4.1 记录字段

| 字段 | 规则 |
| --- | --- |
| 日期 | 必填，默认今天，可补录其他日期，作为日历日期保存 |
| 餐次 | 必填，早餐／午餐／晚餐 |
| 是否计划在家吃 | 必填，是／否；新建默认是，编辑沿用原值 |
| 用餐方式 | 单选；计划在家吃为是时必填，为否时选填；新建默认选中可用的内置“下厨” |
| 制作分类 | 根据方式配置显示，多选且选填，支持搜索已有分类与输入新分类 |
| 菜品内容 | 选填，单行输入，例如“番茄炒蛋、米饭、冷冻饺子” |
| 备注 | 选填，单行输入；对应用户最初所说的“备考” |

新增和编辑表单中的这两个输入框横向滚动显示长文本。打开已有或导入的多行内容时，输入框以空格显示换行，保存时保留原有文字及换行。

同一日期同一餐次最多一条记录。编辑时修改日期或餐次如发生冲突，应提示已有记录，不覆盖、不生成重复项。

已有用餐记录的编辑页底部提供明确的“删除这条用餐记录”按钮；新增页不显示删除。点击后先展示待删除记录的原日期、餐次和菜品摘要，确认后才删除，取消保留当前编辑草稿。删除后更新首页进度，并按当前筛选条件重算统计；不能因编辑中的日期／餐次草稿变化而删除另一条记录。

“是否计划在家吃”表示原先的计划，用餐方式用于记录实际方式，两者独立。例如计划在家吃为否，最后实际下厨，是合法记录。

### 4.2 用餐方式设置

- 初始建立“下厨”和“外卖”两项，使用稳定 ID 引用，不根据显示名称判断业务行为。
- 设置页面支持新增、改名、排序、停用，以及“显示制作分类”开关。
- 默认下厨开启分类开关，外卖关闭；新增项默认关闭。
- 内置“下厨”改名后仍按原 ID 作为新建默认项。该方式停用或不存在时，由用户选择用餐方式。
- 点击用餐方式选项后面的加号打开新增弹窗。确认后加入共享词表末尾，保留本餐已选方式及表单内容。
- 已被引用的方式只允许停用，不硬删除；停用后不供新记录选择，已有记录可以显示并保持原选择。编辑已有记录时，原记录引用的停用方式始终显示并允许重新选择，显示“（已停用）”标识，不会因临时取消或切换到其他方式而消失。
- 改名后记录通过同一个 ID 关联，显示更新后的名称，不创建重复方式。

### 4.3 制作分类与状态切换

- 制作分类是所有启用该能力的方式共用的一套词表，支持多选。
- 点击制作分类选项后面的加号打开新增弹窗。确认后加入共享词表末尾，保留本餐已选制作分类。取消弹窗不创建选项。
- 新增方式和分类在弹窗确认时保存，之后可在其他记录中使用。用餐记录仍通过表单底部的保存操作提交。
- 去除首尾空格，避免规范化后重名；支持重命名、排序、停用，已引用项不硬删除。
- 计划在家吃由是改为否，保留当前方式和分类；由否改为是且尚无方式时，要求补选后才能保存。
- 用户清空方式，或主动切换到关闭分类开关的方式时，保存后清除该条记录的制作分类；取消编辑则不改变原数据。
- 是否清除以保存时的最终方式为准：切换到其他方式后又切回原方式，视为未改变方式。编辑过程中已选的制作分类在表单内暂存，切回启用分类的方式时恢复显示。
- 切换到另一个启用分类开关的方式时可以保留现有制作分类。
- 编辑已有记录时，原记录引用的停用制作分类始终允许重新选择并显示“（已停用）”标识，不会因临时取消勾选或切换方式而消失；新建记录仍不允许选择停用的用餐方式和制作分类。
- 仅在设置里关闭某方式的分类开关，不批量清空历史记录。历史已有分类继续可查看；编辑备注等其他字段且最终方式未改变时，保留原分类，可显示为“历史制作分类”。
- 菜品内容、备注在所有情况下都显示，不随方式切换清空。

### 4.4 查询、复用与统计

- 按日浏览的日期条显示周一至周日。顶部“上一周”“下一周”将所选日期前后移动七天，维持同一星期几并同步日期选择器和三餐记录。点击任一天可直接查看当天，日期选择器可跨月跳转。按日浏览的已记录卡片显示餐次、方式标签与菜品，有制作分类或备注时以次要摘要行展示。

- “用餐 → 记录”与“用餐 → 统计”页头右侧均提供“筛选”入口，点击打开共用的[底部悬浮筛选面板](01-common.md#底部选择面板)（各自保留已应用的条件）。面板顶部保留拖动横条、标题与关闭图标，中间内容可滚动，底部固定“重置条件”与“应用筛选”操作；关闭图标、遮罩点击、顶部标题区下拉及系统返回均丢弃未应用草稿并保留已应用条件。
- 底部筛选面板从上到下依次提供（无二级嵌套弹窗）：
  1. **菜品／备注关键词**：单行输入，有内容时标题右侧可一键清空；
  2. **日期范围**：“本月”（设备当前月份首末日）和“所有时间”（同时清空起止日期，保留其他草稿条件）快捷 Chip，以及可分别选择或清空的“开始日期”“结束日期”（含边界，可留空；有值时“清空”显示在对应日期标题右侧，与下方日期框右对齐；开始晚于结束时提示错误，不应用）；
  3. **餐次**：早餐／午餐／晚餐平铺紧凑多选 Chip；
  4. **是否计划在家吃**：是／否平铺紧凑多选 Chip；
  5. **用餐方式**：在面板内直接平铺各方式选项（停用方式显示“（已停用）”）及“未填写方式”紧凑多选 Chip；
  6. **制作分类**：在面板内直接平铺全部制作分类紧凑多选 Chip（停用项显示“（已停用）”）。（用餐记录编辑页制作分类超过 8 项时的“更多分类”仍通过统一底部多选面板选择。）
- 各筛选维度组合为同时满足；餐次、是否计划在家吃、用餐方式及制作分类均支持多选：全不选表示不限；部分选中或全部选中均保留选中状态并匹配任一所选项，不自动转换为空选（再次打开筛选面板时完整保留上次选中状态；制作分类全选时不包含未填写制作分类的记录；新增选项不自动加入已有筛选条件，删除选项仅清除失效条件并保留其他有效条件）。此规则仅用于筛选，不影响用餐记录编辑与保存。“重置条件”清空其他草稿条件，并恢复入口默认的日期范围（统计为本月，记录为所有时间）。
- 在“用餐 → 记录”中，仅当至少存在一项有效筛选条件（起止日期、餐次、计划在家吃、用餐方式、制作分类或非空关键词）时展示跨日期的匹配记录列表；不保留无条件的空筛选列表态。应用空条件、点击列表标题行右侧“清除筛选”、点掉最后一个已应用条件标签，或在 Android 筛选结果列表页（无子页及弹层打开时）按系统返回键，均立即清除记录筛选并回到按日浏览。
- “用餐 → 记录”处于筛选结果态时，不显示“按日浏览”返回按钮：顶栏左侧保持等宽选择框显示当前筛选日期范围摘要（如`范围：本月`、`范围：所有时间`、`范围：2026年10月`或起止日期，点击打开筛选面板），右侧固定位置显示高亮的`筛选 (N)`按钮，保证筛选前后顶栏结构一致。
- 已应用的筛选条件在“记录”筛选结果和“统计”页上方按选中项逐个渲染为带关闭图标的可点击条件标签（统计页标签不含日期范围本身），点击任一标签立即移除该单项条件并同步更新结果与计数；“记录”筛选结果分组标题行右侧显示匹配条数与“清除筛选”。
- 点开筛选结果中的记录可编辑或删除原记录：保存／删除后保留当前筛选条件并重算结果；从“记录”筛选结果进入已有记录编辑页时，编辑页顶栏右侧提供“查看当天”按钮，点击后丢弃未保存编辑草稿、清除记录筛选条件，返回按日浏览并选中该条原记录所属日期（采用普通子页滑出返回过渡）。
- 已应用的记录或统计条件引用的用餐方式或制作分类被删除（或恢复备份后不存在）时，自动移除该项条件并同步写回原筛选状态（记录筛选若移除后无剩余条件则自动回到按日浏览），避免恢复旧备份后已解除的条件重新生效，同时保留其他有效条件及默认本月统计逻辑；条件标签、计数与实际过滤始终一致。方式字段为空显示“未填写”；引用的方式无法解析时显示“已删除的方式”，不与“未填写”混同。
- 同一日期内的记录按早餐、午餐、晚餐的时间顺序排列，不按餐次标识的字母顺序。
- 匹配记录使用[共用界面规范](01-common.md#31-用餐与账本的共用界面)的紧凑记录行，依次显示菜品、日期与餐次及方式、计划／制作分类／备注摘要。过长的菜品和摘要省略显示，点开可查看完整内容；保持正文字号及原始记录内容。
- “复制上一餐内容”复制上一条较早记录的制作分类、菜品和备注，保留当前日期、餐次及在家吃选择。当前方式未启用分类时不复制制作分类。
- “用餐 → 统计”默认按设备本地日历显示本月，包含当月首日至末日。点页头的日期范围可打开月份选择，通过年份和月份直接跳转，也可切换上个月或下个月。应用后统计覆盖所选月份的首日至末日，并保留其余筛选条件。取消保留已应用的范围。页头右侧“筛选”按钮在存在除日期外的筛选条件时高亮并显示条件数。
- 用餐概览、计划在家吃的是／否餐数、用餐方式和制作分类都按同一批筛选后的记录计算。统计页显示当前日期范围及其他已应用条件。选择“所有时间”后可查看跨月份的统计，匹配记录中的历史停用方式仍参与计数。
- 用餐方式和制作分类的条形按筛选结果的餐数计算占比，保留名称、餐数或次数及百分比。计划在家的是／否以有文字标注的分段条形表示；没有符合条件的记录时显示空状态。
- 用餐方式未填的合法记录单列为“未填写”，不能推断为外卖或其他方式。
- 制作分类逐项计数，分类次数之和可以大于餐数；历史仍保留的分类也按记录计数。
- 不再以旧的“是否下厨”布尔值统计。可以在方式分布中查看下厨次数，但不依赖方式名称硬编码。
