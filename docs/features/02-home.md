# 首页功能设计

> 首页总览及四个底栏入口的共同定义见 [全局导航](01-common.md)。

## 首页专属规则

- 首页不重复用餐页的日期浏览和三餐详情；显示当天记录进度，并按设备本地时间推荐餐次：00:00–10:59 早餐、11:00–16:59 午餐、17:00–23:59 晚餐。对应餐次未记录时显示“记录早餐／午餐／晚餐”，已有记录时显示“编辑早餐／午餐／晚餐”，不跳到另一餐，也不自动创建记录。其他餐次和补录通过用餐页进入；应用回到前台或跨时段时刷新推荐。
- 首页使用 APP 图标与“日常记录”文字作为标题，不显示问候标语、备份是否启用或备份状态入口。备份状态与操作集中在设置页；设置统一由底部导航进入，不常驻右上角。
- 首页“今日用餐”和“本月收支”使用同一层级的独立描边卡片：标题和详情入口均位于卡片内首行（左标题、右详情箭头），随后为摘要信息，底部为全宽主要操作。两张卡片的左右边距、内边距、间距、圆角、描边、标题字号和按钮高度完全一致，采用 [公共组件规范](01-common.md#31-用餐与账本的共用界面) 已有语义尺寸，不另起视觉规格；卡片间距 16dp。首页标题、日期在卡片外，卡片之间不再插入外部“本月收支”标题行。
- “今日用餐”卡片首行右侧为“全部记录”并进入用餐；其下单独显示已记录餐数“n / 3 餐已记录”与三餐状态，底部保留随本地时间推荐的全宽“记录／编辑×餐”操作。
- “本月收支”卡片首行右侧为“查看账本”并进入账本；其下按币种分组，每个币种代码独占行。“净支出”和“收入”通常并排，金额超过列宽时改为上下排列，整栏仍放不下时可换行。金额保留完整数值与小数位。底部保留全宽“记一笔”按钮。
- 首页仅统计常规钱包。没有常规钱包时显示“暂无常规钱包的收支”，并提供快捷记账入口；常规钱包当月无交易时按已有币种显示零金额。
- 本月收支按币种分行展示。存在 CNY 时将 CNY 放在第一行，其余币种依原顺序显示。
