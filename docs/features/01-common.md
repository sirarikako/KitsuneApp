# 全局导航与共用界面

> 本文件维护页面导航、通用视觉组件、全局动效；首页专属规则见 [02-home.md](02-home.md)。

## 3. 信息架构与主要页面

底部四个入口固定为“首页、用餐、记账、设置”。后续新功能优先通过首页功能入口扩展，避免不断增加底部标签。

| 页面 | 内容与主要操作 |
| --- | --- |
| 首页 | APP 图标与“日常记录”标题、当前日期、今日三餐记录进度、按时段推荐餐次的快捷记录、快捷记账、本月按币种展示的收支摘要 |
| 用餐 | 按日浏览、月历定位、历史搜索、记录详情与编辑、用餐方式和制作分类统计 |
| 记账 | 页内“流水、钱包、统计”标签；仅流水页悬浮“记一笔”；日期、钱包、类型、分类与关键词筛选 |
| 设置 | 用餐方式、制作分类、通用收支分类、钱包专属分类（按钱包及收支类型）、外观与调色板、导入导出、本地备份、GitHub 配置 |

- 金额、餐次和保存按钮优先突出；收入、支出、错误与成功同时使用文字或符号表达，不只靠颜色。
- 所有主要页面支持深色模式、大字体和键盘展开；保存按钮不能被键盘遮住。
- 数据为空时提供创建或录入入口；备份未配置、等待、失败和成功都要有明确状态。

### 3.1 用餐与账本的共用界面

| 组件 | 统一规则 |
| --- | --- |
| 导航与筛选 | 共用页标题、页内下划线标签和带边框的筛选控件。用餐记录支持按日浏览，记录与统计共用组合筛选页。账本流水与统计共享日期及钱包范围，可在日期弹窗切换月份和自定义起止日期。 |
| 记录列表 | 三餐、用餐筛选结果和账本流水使用同一记录行组件，共用图标尺寸、主次文字、标签、间距和详情箭头。统一使用带细描边的圆角记录卡片，所有配色沿用同一组件规格。待记录餐次使用加号，用餐历史展示菜品与餐次，账本流水右对齐带正负号及币种的金额。 |
| 录入与详情 | 子页左侧统一放返回按钮，录入共用字段标签、输入框、选项和保存按钮样式。Android 日期和时间使用主题圆角选择弹窗，支持日历或时钟以及格式化输入。日历顶部年月展开年份输入及 12 个月份按钮，选择月份后跳转到该月的日期网格。左右箭头或滑动可逐月浏览，浏览月份不改变已选日期。窄屏日期直接提供 YYYY-MM-DD 输入，时间采用 24 小时制。确定后提交，取消保留原值。校验提示放在操作区，删除使用相同的危险操作样式与确认弹窗。记账金额控件打开底部计算器，计算器使用应用内按键。 |
| 统计 | 共用分组标题、两列摘要、明细面板和横向比例条。用餐条形按餐数，账本按币种和收支分组展示分类金额及占比。 |

**容器与控件统一规范：** 首页收支、今日用餐、用餐／账本记录行、统计摘要与明细、账目详情、设置分组和外观示例均使用主题卡片底色及 1px 细描边，不用整块强调色替代边框，也不因切换视觉方案改为仅底部分隔线。筛选、输入和普通选择共用描边体系。计算器面板和填充按键使用[记账规格](05-ledger.md#53-金额计算器)。纯色强调只用于主操作按钮、明确的当前选中态、危险确认、品牌／状态图标及图表／调色板等具有语义的元素；未选中控件和一般信息卡片不铺大面积强调色。浅色、深色与系统动态颜色都使用相同的语义色角色和交互规则。

**共用设计规格（网页基准，Android 对应 dp／sp 并支持字体放大）：** 间距使用 4／8／12／16／24；普通卡片内边距 16、紧凑记录 12；卡片圆角 17、控件 12、弹窗 24。普通输入、主要与次要按钮最小高度 46，独立图标按钮 44×44，标准图标 18；正文 14、辅助文字 12、标签 11、页面标题 26、分组标题 15。尺寸为基准而非固定高度，长文字允许换行增高。日期、普通选项和制作分类筛选的选中状态使用主题浅色底与主题色描边，保留多选勾选符号；页内标签下划线、底部导航指示和待记录虚线保留各自语义。金额输入保留大字及右对齐，但使用同一描边输入样式。设置下拉控件、账目详情分组与弹窗使用共用样式；计算器使用底部弹层，钱包范围使用底部选择面板，删除确认使用居中弹窗。

所有页面使用唯一的组件造型规范（原杏橙手账），背景、卡片、正文、辅助文字、选中和危险态映射到同一套主题角色。预设、自选及系统动态取色仅改变语义色，不切换布局、形状或动效；不提供独立视觉风格选择，也不新增相应偏好字段。预览中记录行以约 70 CSS px 为基准，长内容及字体放大时允许增高。紧凑历史行可截断摘要，进详情后可读完整内容；金额和币种须可辨认。

### 3.2 全局动效与页面过渡

动效以轻量、柔和、克制、有连续感为原则。首页、用餐、记账、设置及其子页共用同一套规则；不同预设、自选主色、浅色、深色和系统动态颜色不得分别定义页面切换方式。以下时长为完整单次过渡的设计基准（毫秒），不是操作生效前的等待时间。

| 场景 | 动效 | 时长 |
| --- | --- | ---: |
| 底部四个一级页面之间切换 | Fade Through：旧内容淡出，新内容淡入并从 96% 轻微缩放到 100%；页标题与内容一起过渡，底部导航、系统状态栏位置保持固定。 | 200 |
| 进入全屏子页面（新增、录入、组合筛选、下一级设置等） | 每深入一层，新页从右侧水平滑入，原页轻微向左移动；只作用于页面区域。 | 240 |
| 全屏子页面返回 | 当前页向右滑出，上一级页面从左侧轻微滑回。适用于任意层级，系统返回与页面返回方向一致。 | 220 |
| 点击已有记录卡片进入详情（用餐记录编辑、账目详情） | Container Transform：从被点击记录的边界、底色和圆角展开至详情页面，返回时收回原位置；无可见或有效源卡片时使用普通子页面进入／返回。 | 280（双向） |
| 底部弹层（如计算器及选择面板） | 自底部滑入／滑出，背景遮罩同步淡入／淡出；保留原页位置。 | 250 |
| 居中弹窗（含删除确认、日期范围） | 96% → 100% 缩放并淡入，退出反向；遮罩同步变化。 | 180 |
| 页内标签、按日／月浏览、月份及筛选结果变化 | 内容区域短淡入淡出，标题、日期控件、页内标签、底部导航及悬浮操作按钮不跟随切换动效；不对每条记录依次播放动画。 | 150 |
| 外观草稿预览区显示／隐藏 | 示例及操作按钮作为整体淡入并平滑展开高度；退出时反向收起，草稿状态以[外观草稿规则](07-appearance.md#64-预览保存和备份)为准。 | 200 |
| 成功应用外观 | 已应用的主题语义颜色在全应用同步平滑过渡，不切换布局、不重建导航栈；与预览区收起同时进行。 | 250 |

**适用优先级：** 现有信息架构及业务交互保持不变。已有底部弹层／居中弹窗优先使用对应动效；有效记录卡片来源优先容器变形，不再叠加水平滑动；其他全屏子页使用层级滑动；同级底栏导航使用 Fade Through，页内更新使用短淡入淡出。新增记录、快捷入口没有有效详情源卡片时使用普通层级滑动。此表不要求把已有全屏表单或筛选改成弹层，也不新增页面、选择器或业务入口。

**共用实现约束：**

- 统一缓动基准为 cubic-bezier(0.2, 0, 0, 1)（Compose 对应共用 CubicBezierEasing）；时长、缓动与缩放比例集中管理，业务页面只按场景选择动效，不自行定义。避免 3D 翻转、大幅独立缩放、弹簧回弹、夸张视差及重复叠加动画。容器变形的几何展开不受普通淡入缩放比例限制。
- Fade Through 的背景始终保持不透明的主题背景，旧内容淡出与新内容呈现平滑衔接，无中间白屏；一级切换不改变目标页面既有滚动位置、筛选条件和表单状态。底栏选中态立即跟随目标，重复点击当前页不重播。
- 一级页和全屏子页之间切换时，过渡区域保持尺寸和顶部位置。主导航留在原位，由滑入的子页逐步覆盖，返回时随子页向右滑出逐步露出；子页停稳后隐藏主导航。一级页恢复原滚动位置时预留主导航高度，正文限制在导航栏上方。
- 导航和业务状态立即更新；连续点击或快速返回允许中断、重定向动画，从当前显示状态收敛到最后一次有效操作，不排队、不阻塞触摸，不产生重复路由。离场内容仅为视觉呈现，不可继续接收触摸或无障碍焦点；焦点按目标页面或弹层语义恢复。遵守原有表单保存、取消、返回及删除确认规则。
- 动效不等待网络、数据库或备份完成；内容未就绪时按既有加载／空状态规则展示，禁止用动画掩盖错误或延迟反馈。优先使用透明度、位移与轻微缩放，避免让整页逐帧反复测量、重建或产生明显卡顿。
- 尊重 Android 系统动画缩放与减少动态效果的偏好；系统关闭动画时即时切换、展开及收起，减少动态效果时取消位移／缩放／容器变形并采用短淡入淡出或即时切换。不增加独立的应用动效设置。主题过渡中关键内容仍应清晰可读，必要时直接切换成对的前景／背景语义色；不得为了插值而破坏关键文字对比度。


### 底部选择面板

钱包、分类、币种、动态用餐方式、导入映射及账本钱包范围／流水筛选使用统一悬浮底部面板。面板使用主题卡片底色、大圆角、无外描边和顶部短拖动指示。标题约 18sp、SemiBold，分组标题约 14sp、Medium；关闭图标约 22dp，触控区至少 48dp。普通选项无边框、左对齐，单行最小高度 48dp，附辅助信息时至少 64dp。项目间距 0～2dp，功能分组间距约 12～16dp。文本可换行并增高。

- 钱包、分类、币种等单选列表以主题浅底和右侧对勾表示当前项，保留图标和辅助文字。
- 钱包及分类等长列表多选仅以右侧复选框表示选中，正文、辅助文字、图标颜色和背景保留普通样式，整行可点击。
- 少量固定互斥模式使用等宽横向分段控件，当前模式使用主题浅底。少量固定多选项使用选中时带对勾与主题浅底的紧凑 Chip，宽度不足时自动换行。

标题、搜索栏和底部操作固定，长列表按需渲染并在可用高度内滚动，新打开时从顶部显示。滚动内容与底部操作间距 12dp，面板内部底边距 12dp。键盘展开时列表适应剩余高度，输入和应用操作保持可用。主操作使用主题实色按钮，辅助操作使用文字按钮。单选立即回填当前页面，多选在点击“应用”后生效。遮罩、下滑、返回及关闭图标丢弃未应用的草稿。Activity 重建时保留打开的面板、草稿和列表位置。
