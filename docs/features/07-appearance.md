# 外观与图标设计

> 全局组件造型及动效见 [公共规范](01-common.md)，本文件维护外观设置及图标要求。

## 6. 外观、调色板与系统主题

### 6.1 独立的两个设置维度

入口：“设置 → 外观与调色板”。

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 明暗模式 | 跟随系统／浅色／深色 | 跟随系统 |
| 配色来源 | 预设调色板／自选主色／跟随系统壁纸（系统动态取色） | 预设调色板 |

明暗与配色来源可以自由组合，例如“茶绿＋跟随系统明暗”或“系统动态取色＋固定深色”。

### 6.2 预设与自选颜色

| 预设 | 种子色 |
| --- | --- |
| 杏橙（默认） | `#C47A4A` |
| 茶绿 | `#5F7F64` |
| 雾蓝 | `#587C9B` |
| 薰衣草 | `#8A729F` |
| 豆沙粉 | `#A76F82` |

- 自选主色同时支持可视化取色器和六位 HEX 输入，接受带或不带 `#`，保存为规范化不透明 RGB 颜色，不提供透明度。
- 第一次自选以杏橙初始化。无效 HEX 不允许应用，不丢失上次有效颜色。
- 预设与自选主色以 Material Color Utilities 的 Tonal Spot 色彩方案构成完整浅色与深色 ColorScheme。应用的背景、卡片、描边、文字、选中、主要操作和收支使用与 HTML 预览相同的展示色值及对比度规则。其他 Material 角色由 Tonal Spot 提供。
- 各预设从自己的种子色派生页面背景、卡片底色、柔和底色和描边。浅色、深色都用同色系的独立色阶区分页面和卡片，卡片比页面底色略亮。调色草稿预览和应用后的页面使用相同色阶。
- 为主色、辅助色、卡片、背景、文字、边框、选中态提供统一主题颜色；业务页面不得散落硬编码品牌色。
- 收入、支出、成功、错误采用独立语义色，并适配明暗模式；配色不能让金额类型只能靠颜色判断。

### 6.3 系统跟随与兼容

- 明暗“跟随系统”响应系统明暗变化；固定浅色／深色时不跟随变化。
- 系统动态取色使用系统提供的 Material 配色，不自行读取或上传用户壁纸。
- 浅色和深色都从系统配色选取不同的中性色阶。页面使用较深的底色，卡片及分块使用较浅的底色，保留细描边；草稿和应用后的界面采用相同规则。
- 设置中的可见名称为“跟随系统壁纸”，对应现有 colorSource=SYSTEM，不增加另一套重复主题类型；与“跟随系统明暗”分别设置。UI 预览提供标明示意的动态色板，真实壁纸取色在 Android 中接入，不能将网页示意颜色当作实际读取结果。
- 动态取色在 Android 12／API 31 及以上可选；较早版本禁用该选项并说明版本要求。
- 恢复备份到不支持动态取色的设备时保留用户偏好，实际使用保存的预设，缺省为杏橙；明暗设置仍有效。
- 切换来源时保留上一次预设、自选主色，以便切回。
- 系统栏与应用内容统一适配；应用回到前台时也能刷新系统配色。
- 冷启动时，系统启动窗口与读取中的界面共用随系统明暗变化的中性底色。第一帧业务内容直接使用读到的已保存外观；首次安装使用新建数据库中的默认外观。颜色过渡用于后续应用外观。

### 6.4 预览、保存和备份

- 调色页展示用餐卡片、收入／支出行、标签、按钮和背景预览。独立的“预览明暗”控件只切换示例区域的浅色或深色；“明暗模式”控件编辑将应用到全局的明暗偏好。
- 全局明暗、配色来源、取色器、HEX 和预设均先写入草稿，点击“应用”后全应用更新，无需重启。独立预览明暗与草稿一起使用，提交内容只包括实际应用偏好。
- 草稿与已应用的外观设置不同时，才显示示例、预览明暗及“取消”“应用外观”按钮。成功应用、取消或手动将草稿改回已应用值后，立即进入隐藏状态并按[全局动效规则](01-common.md#32-全局动效与页面过渡)收起整个预览区；离场期间不可继续操作。HEX 按规范化后的颜色值比较。
- 取消不改变已应用设置；“恢复默认”恢复跟随系统明暗、杏橙预设，仍通过应用按钮提交。
- 只在应用实际不同的设置时持久化并触发一次备份；拖动、无变化提交、系统明暗或壁纸变化不产生备份。
- 主题设置纳入 JSON 完整备份，换机后可以恢复。
- 普通正文及重要文字与背景的对比度验收目标至少为 4.5:1；极浅、极深和高饱和种子色都应保持可读性。 外观草稿预览使用与应用相同的颜色生成与组件样式，独立覆盖全部主题角色（含卡片底色、描边和主操作色），不继承已应用主题的对应派生色；为选中态、普通正文、辅助文字、主操作和危险操作分别校验前景／背景对比度，不限制自选种子色。

## 7. APP 图标

狐狸透明源图及 Android 图层保留于 [artwork](../../artwork/README.md)。Android 启动器与首页使用原创资产，网页首页使用同源缩略图。启动器图标的设备验收待完成。

### 7.1 视觉规格

- 原创、正面卡通狐狸头像，暖橙色毛发、奶白色脸颊、圆润脸部、尖耳朵、轻微微笑。
- 扁平插画风，轮廓清楚，缩小后仍容易辨认。
- 彩色图标使用奶油色背景，不加文字、水印或多余装饰，与柔和生活卡片风格协调。
- 不将狐狸永久画入已裁切的圆角方形中；背景与前景分离，由 Android 启动器决定最终外形。

### 7.2 资产与接入

- 优先复用 artwork 中保留的透明彩色前景、独立背景和单色层；如用户要求修改形象，再按可用 imagegen 技能使用内置图像生成工具调整，并保留原始来源与提示词。
- 保存高分辨率源图和项目使用的最终资源到仓库，不能只引用会话或工具默认输出目录。
- 配置 Android Adaptive Icon 的前景、背景和独立单色层；单色层要保留狐狸的识别特征，不能简单变成一个没有五官的实心轮廓。
- 按 108×108 dp 图层设计，主体关键内容在中央 66×66 dp 安全区域，适配圆形、圆角方形等遮罩，不预画外部投影或遮罩。
- 支持 Android 13 及以上兼容启动器的主题图标。彩色版保持品牌配色，单色版由系统主题着色；应用内调色板不直接改写桌面图标资源。
- 接入启动器图标资源与 manifest，检查不同形状、主题模式和实际小尺寸效果。
- 工程内保留最终生成提示词及资产说明，便于后续继续修改同一形象。
