# 分类管理功能设计

> 通用收支分类与钱包专属分类统一在此维护；用餐制作分类继续归属用餐模块。

## 5.2 收支与分类

- 每条收入／支出包含日期、时间、钱包、正数金额、对应类型的一个分类和可选备注。收入、支出、转账和退款都必须记录业务发生时间，精确到分钟（24 小时制 HH:mm）。新建时日期和时间从打开表单时的设备本地时钟一次性带入，允许手动修改；保存时不覆盖用户选择，编辑旧记录时保留原日期和时间。
- 收入、支出分类分别管理，采用一级分类，支持创建、改名、排序、停用和录入时新增。原有分类作为“通用分类”，分别适用于所有未启用专属分类的钱包。
- 账本设置 → 分类管理分为“通用收支分类”（收入／支出分别管理）与“钱包专属分类”（先选钱包，再选收入／支出）。钱包管理页提供直达该钱包分类管理的入口；用餐制作分类维持原设置，不与账本分类混用。
- 分类列表显示图标、名称及停用、兜底等状态。新增和编辑收支分类时可从默认标签、餐饮、交通、居家、工作、财务、购物、健康、礼物、教育、旅行、娱乐中选择图标。点可编辑的分类行进入详情，可修改图标、名称、排序和启停。通用模式下查看的钱包通用分类为只读，仍提供管理已保存专属分类的入口。
- 每个钱包的收入、支出可独立选择“使用通用分类”（DEFAULT）或“使用专属分类”（CUSTOM），默认两个方向均为 DEFAULT。只有选 CUSTOM 的方向才用该钱包的专属类别集合替代通用自定义类别；不将两套类别混合展示。CUSTOM 即便还未新增任何类别，也只显示“未分类”，不因列表为空偷偷恢复通用类别；明确切回 DEFAULT 后才采用最新通用列表。先前创建的专属类别保留以供历史记录和再次启用。
- 各个收支方向全局仅保留一个稳定 ID 的“未分类”兜底项，不允许删除／停用。无论 DEFAULT 或 CUSTOM 都在可选列表中提供该兜底项；钱包专属分类不能重复创建“未分类”。类别引用按 ID 而非名称；专属类别持有归属 walletId，通用类别 walletId 为 null，规范化名称在相同收支类型与同一归属内唯一，允许不同钱包出现同名类别。
- 新记账及记账编辑按所选钱包和收支类型获取有效类别。切换钱包或类型后，当前类别若不属于新钱包的有效范围，先清空并提示重新选择（不得悄悄记入另一钱包的同名类别）；新建默认可选择该范围的“未分类”兜底项。历史引用即使已停用、从 CUSTOM 切回 DEFAULT，或通用类别改名／停用，仍可展示；仅修改备注或金额不应改写原有分类，用户显式重选分类时才校验当前有效范围。
- 记账表单在分类标题右侧提供“新增分类”，与下拉框右边缘对齐。弹窗保存名称和图标后，立即在当前钱包的分类范围内创建分类并选中，保留其余记账草稿。取消弹窗保留原分类，保存分类后退出记账表单仍保留该分类。下拉框选中项和候选项均显示分类图标，未自选图标的分类使用默认标签图标。
- 已被引用的普通分类只停用、不硬删；重命名通过引用反映到历史记录。退款沿用原支出实际的 categoryId，与退款到账钱包的默认／专属类别模式无关。分类统计按 categoryId 汇总，跨钱包相同名称但不同 ID 不强行合并；同名时显示所属钱包避免误解。
- 新建默认支出、今天、最近使用的未归档常规钱包；最近使用的是独立核算钱包时忽略它，改用最近使用的常规钱包；若没有可用常规钱包则钱包留空等待手选。记住的分类必须匹配当前收支类型。
- 首版编辑不把已有流水跨类型转换；需要转换时删除原记录后新增，受退款关联等约束保护。
