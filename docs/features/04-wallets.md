# 钱包功能设计

> 钱包实体、独立核算和分类模式的来源规则集中维护于此。

## 5.1 钱包

- 每个钱包保存名称、ISO 币种及其 currencyScale、初始余额、排序、归档状态和 `separateAccounting`（独立核算，默认 `false`）。同一数据集内“规范化名称＋币种”唯一，使 CSV 映射无歧义；不同币种允许同名钱包。
- 钱包新增与编辑界面提供“独立核算”开关；钱包列表始终显示所有钱包，并用“独立核算”标识已开启的钱包。可在有历史流水后切换此开关，立即刷新展示与筛选结果，但不修改历史流水、钱包余额、分类、关联退款或转账。此开关只控制默认统计／筛选范围，不是数据隔离、归档、禁止记账或额外账本。
- 钱包卡片以当前余额为主要读数。名称、币种及“独立核算”“已归档”标识列在上方，右上角铅笔按钮进入钱包编辑。初始余额与核算说明置于余额下方，底部用文字按钮进入本钱包分类管理。
- 币种精度跟随所选货币，例如 JPY 为整数，CNY 为两位小数；不使用固定两位小数处理所有币种。
- 初始余额允许为正、零或负，钱包当前余额允许为负。
- 余额由初始余额和全部相关流水计算。派生余额按最小货币单位用任意精度整数计算和展示，可超过单笔金额的 64 位范围。
- 修改初始余额会重新计算余额，不计为收入或支出。
- 钱包产生流水后不能改变币种或精度；已有流水的钱包只能归档，历史数据和统计保留。
- 初次没有钱包时，引导先创建钱包；归档钱包不作为新账目默认选择，历史账目仍可查看。新收支、快捷记账和转账／退款的可选钱包列表仍允许用户明确选择未归档的独立核算钱包，但默认钱包只从未归档常规钱包中选最近使用者；若无常规钱包，不预选独立核算钱包，提示用户手动选择。编辑历史账目保留原钱包（含归档、独立核算）。
- 钱包另保存 `incomeCategoryMode`／`expenseCategoryMode`（`DEFAULT`／`CUSTOM`，默认均为 `DEFAULT`），分别控制收入、支出分类范围；与 `separateAccounting` 无关，不要求独立核算钱包才能使用专属分类。钱包页可直接进入该钱包的分类管理。
