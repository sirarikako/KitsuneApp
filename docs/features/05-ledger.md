# 记账功能设计

> 包含收支录入、计算器、转账、退款、流水查询和统计；钱包及分类规则分别维护于对应模块。

## 5. 记账功能详细规则

> 本文仅涵盖原 §5.3–§5.6；原 §5.1 钱包规则见[钱包](04-wallets.md)，原 §5.2 收支与分类规则见[分类管理](06-categories.md)。

### 5.3 金额计算器

- 支持数字、小数点、加减乘除、退格、清空、等号，不做科学计算器或任意脚本求值。
- 采用通常的乘除优先于加减规则，例如 `12+8×2` 为 `28`。
- 将有限小数解析为精确分数，保留除法产生的分数直到整条表达式计算结束。只在最终按钱包货币精度采用 HALF_UP 四舍五入，并展示待保存结果。例如两位小数的钱包中，`1÷3×100` 得到 `33.33`。
- 单笔金额及钱包初始余额以币种最小单位的有符号 64 位整数保存。退款累计、派生余额和统计加总使用任意精度整数，结果按币种精度直接格式化。
- 除零、非法表达式、舍入后超出单笔金额范围或最终非正数时保留输入并提示错误。编辑或删除后的派生余额可以超过 64 位范围，按精确金额正常显示。
- “记一笔”主表单采用紧凑的单页布局：日期时间（支持时、分）、钱包与分类（同一行）、备注、金额，最后保存；收支类型放在页标题区。金额可直接输入，旁边提供“计算器”入口，默认不常驻完整计算键盘。计算器以底部弹层打开，“使用此金额”后回填结果并关闭；取消、返回或关闭保留原金额。打开／关闭和计算不得清空日期时间、钱包、分类、备注等草稿。常规字号且键盘关闭时以一屏完成为目标；大字体或键盘展开时允许滚动，确保保存按钮可达。

### 5.4 转账

- 一次转账选择两个不同钱包，作为一条整体业务记录提交、编辑和删除，数据库操作必须原子化。
- 同币种：转出和到账金额相同，填写一侧即可同步另一侧。
- 跨币种：分别填写转出金额和到账金额，例如 CNY 100 → JPY 2,000，不要求维护汇率。
- 转账不计入收入或支出，分别影响两侧钱包余额。
- 手续费单独记录为支出，不隐藏在跨币种转账金额或统计中。

### 5.5 退款

- 从原支出发起，支持部分或全部退款；退款为独立记录并引用原支出。
- 退款进入与原支出相同币种的钱包，默认原钱包；钱包不同但币种相同也允许。
- 累计退款不得大于原支出金额，退款金额必须为正。
- 退款按自身发生日期和到账钱包计入流水，抵减该日期及钱包范围内原支出分类的净支出。当期净支出可以为负。例：同币种的 A 钱包支出 100，B 钱包到账退款 30，在两笔均落入所选日期范围时，单选 A 的净支出为 100，单选 B 为 −30，合选 A 和 B 为 70。
- 退款分类由原支出决定，不独立编辑。修改原支出分类后，统计按其当前关联分类保持一致。
- 修改原支出金额不得小于已退款总额；存在退款时不得将原支出改成不兼容币种；删除原支出前必须先删除关联退款。
- 修改或删除退款后，余额、剩余可退金额和统计同步更新。

### 5.6 查询与统计

- 流水支持日期范围、钱包、类型、分类和备注关键词筛选，默认展示当月，按业务日期、业务时间倒序；同一分钟的记录再按 createdAt 倒序、ID 升序稳定排列。流水行和详情显示业务时间。分类筛选以类别 ID 为准：通用与钱包专属类别均可检索（含当前筛选钱包中仍有引用的历史停用类别），同名类别不得被误选为同一类别。
- 流水与统计共用一个已应用的日期范围。默认使用本月，月份选择器可直接选择年月或切换上／下个月。自定义范围必须填写开始、结束日期，可跨月且包含两端；应用后替换月份范围，两个标签都显示实际起止日期。选择“返回按月”回到上次所选月份。取消或输入无效时保留已应用范围。
- 日期与钱包范围同时作用于流水、收支摘要和分类统计。钱包范围默认是“常规钱包”（`separateAccounting=false`，包括仍需显示历史的归档钱包），排除独立核算钱包；“全部钱包（含独立核算）”是用户明确选择的另一种范围，不得把它与默认范围混为一谈。筛选器可选默认常规钱包、全部钱包或任意一个／多个具体钱包；独立核算钱包在候选列表中始终可见但默认不勾选，附“独立核算”标识。手动选择的范围跨“流水／统计”标签保留，重新进入页面也沿用已应用范围；用户点“恢复默认”才回到动态常规范围。切换钱包的独立核算属性时，默认范围实时重算，已显式选择的具体钱包 ID 不被静默增删。无常规钱包时默认范围为空，显示提示与手选入口，不自动纳入独立核算钱包。全部／多选范围内，同币种钱包汇总，不同币种分别列出；历史归档钱包仍可选。流水的类型、分类、备注关键词筛选只影响流水列表。转账行显示两侧钱包，所选钱包命中任一侧时展示一次，且转账不计入收支统计。流水行、详情和删除确认明确显示所属钱包及币种。
- 点击流水行进入账目详情，详情底部提供“删除这笔账目”；确认弹窗展示日期时间、分类、类型及金额，确认后删除并刷新流水、收支统计和钱包余额，取消不改变记录。转账整体删除，原支出存在关联退款时需先删除退款，沿用前述约束。
- 统计展示所选期间的收入、可为负数的净支出和分类排行。空期间显示零金额及无账目提示。首页本月收支固定采用常规钱包范围，不受账本页的手选范围影响；独立核算钱包默认不参与首页、账本流水、收支摘要和分类排行，但用户可以在账本显式选择后查看。钱包管理页始终逐一显示全部钱包的完整余额，独立核算与否不影响其余额公式。归档钱包的历史流水在被当前范围纳入时仍参与相应期间统计。
- 所有统计按币种分别展示，不把不同货币直接相加，也不展示没有汇率依据的统一总资产。
- 转账不计收支；退款抵减支出；初始余额不计收入。余额公式包含所有流入流出，不能只用当月流水推算。
